# 第2章 基础知识 · 2.2 图像数据结构与彩色空间

## 图像模式

- 灰度图：常用 8 bit，范围 `0-255`，共 256 级。
- 二值图：只有 `0/1`；常由灰度图阈值化得到。
- RGB 彩色图：每像素含 R/G/B 三分量；各 8 bit 时共 24 bit，可表示 `256^3=16,777,216` 种颜色。

## 彩色空间

- RGB：面向发光与显示设备，加色模型。
- CMY/CMYK：面向印刷与反射物体，减色模型。
- HSI：色调 Hue、饱和度 Saturation、强度 Intensity，更接近人的颜色描述。

RGB→HSI 常用公式：

\[
I=\frac{R+G+B}{3},\qquad
S=1-\frac{3\min(R,G,B)}{R+G+B}
\]

\[
\theta=\arccos\frac{\tfrac12[(R-G)+(R-B)]}
{\sqrt{(R-G)^2+(R-G)(R-B)}}
\]

若 `B≤G`，`H=θ`；否则 `H=360°-θ`。

### 三位小数示例

`R=100,G=150,B=200`：`I=150`，`S=0.333`，`θ=150°`，因 `B>G`，所以 `H=210°`。

PPT 对应页：12-19；色调公式在第 18 页。

## 补讲：RGB 转 HSI 的实际步骤

1. 先算强度 `I`，它是三个通道的平均。
2. 再算饱和度 `S`。若 `R=G=B`，颜色是灰色，`S=0`。
3. 用反余弦先得到 `θ∈[0°,180°]`。
4. 用 `B≤G` 或 `B>G` 判断色调落在色环的哪一半，得到最终 `H∈[0°,360°)`。

为什么还要第 4 步？因为 `arccos` 只返回 `0°-180°`，无法单独区分色环上下半圈。

特殊情况：`R=G=B` 时色调没有物理意义，公式分母也可能为 0。答题可写 `S=0，H 置 0 或不定义`，不要强行除零。
