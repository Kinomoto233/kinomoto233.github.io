# 3.2 直接灰度变换

- 对数变换：
  - 形式：$$s=c\log(1+r)$$
  - 作用：扩展暗部灰度、压缩亮部灰度，适合增强暗区细节。
- 幂次变换：
  - 形式：$$s=cr^\gamma$$
  - $\gamma<1$ 时提升暗部，$\gamma>1$ 时压低暗部、强调亮部。
- 分段线性变换：
  - 通过设定 $(r_1,s_1)$、$(r_2,s_2)$ 等控制点，对不同灰度区间采用不同线性映射。
  - 可用于灰度拉伸、对比度增强和指定灰度范围突出。
- 自动灰度拉伸：可根据图像灰度最大值、最小值自动设置映射区间。
