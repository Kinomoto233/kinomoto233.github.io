# 5.3 噪声模型与滤波

- 高斯噪声：
  - 由均值 $\mu$ 和标准差 $\sigma$ 描述。
  - 大量自然噪声和传感器噪声可近似为高斯分布。
- 瑞利噪声：适合描述近似偏移的直方图。
- 伽马噪声：由参数 $a$、$b$ 描述，$b$ 为正整数。
- 指数噪声：伽马噪声在特定参数下的特殊情况。
- 均匀噪声：在 $[a,b]$ 范围内概率相同。
- 椒盐噪声：像素随机变为极暗或极亮，常见为 0 和 255。
- 周期噪声：
  - 来源于电力或机电干扰。
  - 唯一一种空间依赖型噪声。
  - 可通过频域滤波显著减少。
- 噪声估计：
  - 理想方式是用同一传感器拍摄纯色对象，估计噪声概率分布。
  - 可用均值 $\mu=\sum_i z_i p(z_i)$ 和方差 $\sigma^2=\sum_i (z_i-\mu)^2p(z_i)$ 描述。
